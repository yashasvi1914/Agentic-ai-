# CrewAI Agent

## Overview
This project demonstrates a multi-agent AI workflow
using the CrewAI framework and Google's Gemini model.

## Technologies Used
- Python
- CrewAI
- Google Gemini
- Jupyter Notebook

## Features
- AI agents with specific roles and goals
- Task assignment and execution
- Collaborative agent workflow

## Project File
- `crewai_gemini_clean.ipynb` - Main notebook.
